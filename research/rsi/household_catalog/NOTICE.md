# Asset attribution and scope

Source household data: OpenRobotLab/GRScenes, GRScenes-100/home_scenes.
https://huggingface.co/datasets/OpenRobotLab/GRScenes

The upstream model data is CC BY-NC-SA 4.0. Model identifiers, source hashes,
and dependency hashes are retained in expected_catalog.json; the original
upstream README is GRScenes_SOURCE_README.md (whitespace formatting normalized). Model binaries are external.
Data-derived geometry and section images retain the upstream data terms.
The Python code follows the repository root license.

The R35 source snapshot is a working controller baseline with offline checks,
not a completed physical-stability release. Evidence in this directory records
historical observations and explicit failures; it is not a 20-object success claim.
