# QV 版本说明

最新补充：QV23已经完成T01–T09的无录像功能验证，加上此前同版本T10，十项均成功。原50个视频仍分别来自QV13/QV22/QV23，没有改写其版本。T02–T05出现耗时回退，详见[统一版本功能报告](UNIFORM-QV23.md)。

QV 是本项目用于区分程序修订、冻结源码和对应运行证据的编号。它不是机器人型号、地图编号或策略训练轮次。每次录像都必须对应真实运行的源码提交；后续代码改动不会追溯改变旧录像。
