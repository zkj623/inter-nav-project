# 交付文档排版约定

适用：《交付说明与测试用例》《测试报告与可视化材料》《算法设计文档》的Word和PDF。

参考公开的技术报告及系统测试报告编排方式，并按交付要求统一使用宋体和黑白版式。参考资料用于结构与排版设计，不表示文档已完成标准符合性认证。

- [承德市科技计划项目验收工作规程及附件编排要求](https://kxjsj.chengde.gov.cn/art/2021/12/6/art_11000_846895.html)：参考标题分级、段落、表格及图注的组织方式；字体按本项目要求统一为宋体。
- [上海交通大学系统测试报告示例](https://plan.sjtu.edu.cn/info/1064/1980.htm)：参考测试报告文档组织方式。

## 统一样式

| 项目 | 设置 |
| --- | --- |
| 纸张 | A4，纵向 |
| 页边距 | 上下2.3cm，左右2.5cm |
| 字体与颜色 | 宋体（SimSun），黑色；表格白底黑线 |
| 封面标题 | 22磅，加粗、居中 |
| 一级标题 | 16磅，加粗 |
| 二级标题 | 14磅，加粗 |
| 正文 | 小四，12磅，1.5倍行距，首行缩进2字 |
| 表格 | 五号，10.5磅，1.15倍行距，表头加粗 |
| 图注与页眉页脚 | 9磅；图注与页码居中 |
| 插图 | 保留原视频截图与来源标注，图片内容保持原样 |

排版脚本：`document_layout.py`。生成脚本`format_documents.py`在写入文档后调用统一样式处理。发布前导出PDF，检查标题、表格、截图、分页和文件完整性。
