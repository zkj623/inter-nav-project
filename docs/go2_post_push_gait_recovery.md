# Go2 推箱后退让的步态启动

2026-10-31。**原始 T04/T05 尚未在当前版本统一完成。** 本页记录启动问题的复现和候选修复；空地诊断不代表原始导航通过。

## 实际故障

原始 T04 v191 已将 B06 真实侧推约0.899m，之后在退让阶段超时，最终距目标1.351m。全程最大倾角3.393°，启动1.679°。新的反向推箱轴曾在126.825s成功选中，后退指令已送入policy；不能把后续的“无可用退让方向”事件理解成从未选中过方向。

为取得确切状态，v193从原始起点和空地图完整重跑，仅增加只读记录。137.35s全程17168条控制记录的位置、姿态、命令、电机目标和观测地图数量与v191逐条一致。6867次45维观测重新打包及离线Actor推理的最大误差均为0。记录包含真实关节角、关节速度、上一动作、根部速度、原始Actor输出及200Hz后段电机力矩。

## 候选行为和边界

普通导航和初次退让仍使用原命令。只有加载器已确认的Unitree45策略出现原有实测停滞条件，并经过原0.4秒停稳检查后，安全轴选择和对应跟踪器才使用0.45m/s的反向主分量。

选择、锁定目标、后续地图变化和每次指令生成都按同一速度重新检查。所需距离仍为`max(目标距离, 0.60*速度 + 速度²/(2*0.65))`，覆盖完整机身、步幅和制动范围；保留未知区域、箱体、0.04m终点余量及实际制动检查。若更大步幅越过安全空间，则拒绝该动作。原速度渐变、12秒恢复期限、总技能期限、重试预算、在线更新和目标验收保持原设置。前进及侧移速度未提高。

没有替换或重训权重。使用的是基于宇树RL Lab自行训练的policy，不是宇树出厂控制器。恢复命令必须在完整原场景中验证，不能从上表推断成功率。
